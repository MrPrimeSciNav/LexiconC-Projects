# Lexicon C# Course Projects

This repository contains C# console application projects and tasks completed as part of the C# course in the IT-education programme at Lexicon, Gävle.

## Structure

- Each folder (`ConsoleApp1`, `ConsoleApp2`, ..., `ConsoleApp17`) contains a separate project or assignment.
- Projects cover various topics in C# programming, including basic syntax, arrays, classes, methods, and more.

## How to Run

1. Open the desired project folder in Visual Studio Code or your preferred IDE.
2. Restore and build the project using the .NET CLI:
   ```sh
   dotnet restore
   dotnet build
   dotnet run
   ```
3. Make sure you have the correct .NET SDK version installed (recommended: .NET 9.0).
